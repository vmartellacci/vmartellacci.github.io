Política de privacidade

App: Google Health e Yazio (uso pessoal de Victor Martellacci Maciel)

Quais dados são acessados

Com autorização expressa do titular da conta, o app lê dados de nutrição, atividade física e medidas corporais (como peso) no Google Health e pode registrar refeições nele.

Como os dados são usados

Os dados são usados apenas para gerar resumos e acompanhamento da dieta do próprio titular. Não são vendidos, compartilhados com terceiros nem usados para publicidade.

Armazenamento

As credenciais de acesso ficam guardadas de forma privada no ambiente do titular. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.
